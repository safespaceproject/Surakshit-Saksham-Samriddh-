SAFESCAPE 360° — Test Cases

Purpose

These test cases describe how to check the SAFESCAPE 360° demo website.

Test Case 1: Website Loading

- Action: Open the website URL.
- Expected Result: The homepage and safety project information are visible.

Test Case 2: Report Form Visibility

- Action: Navigate to the Demo Report form.
- Expected Result: Category, General Area, Additional Details, and Submit Demo Report are visible.

Test Case 3: Submit a Demo Report

- Action: Enter sample information and submit the form.
- Expected Result: The demo report appears on the page and a success message should be displayed.

Test Case 4: Empty Form

- Action: Submit the form without completing required fields.
- Expected Result: The website should ask the user to complete the required fields.

Test Case 5: Mobile Compatibility

- Action: Open the website on a mobile phone.
- Expected Result: The content and form remain readable and usable.

Limitations

These are planned manual test cases. Actual results must be checked on the live website. The current prototype does not permanently store reports or send them to authorities.
