🌍 About the Project

SAFESCAPE 360° is a digital prototype promoting women's safety and safer public spaces through awareness, safety signage and better-lighting recommendations.

🎯 Key Features

- 💡 Promotes better lighting in public spaces
- 🪧 Encourages visible safety signage
- 📝 Includes a demo safety-report form
- 🤝 Promotes community participation

⚙️ Technology

HTML • CSS • JavaScript • GitHub Pages

🏗️ Architecture

User → Web Interface → Safety Form → Demo Report Display

See "architecture.md" for the technical overview.

🧪 Testing

Manual test cases are documented in "tests.md".

🔐 Limitations

This is a prototype. Reports are not permanently stored or sent to authorities. Use fictional data for demonstrations.
